# README 시연 자료

사진과 GIF는 프로젝트 루트 [README](../../README.md)에만 표시하며, 실제 파일은 이 폴더에 보관합니다. 전체 아키텍처와 기능별 상세 문서는 텍스트와 구조도로 설명합니다.

현재 미디어 파일은 아직 추가하지 않았습니다. README에는 표시 위치를 알리는 안내 문구와, 나중에 사용할 이미지 문법·캡션을 숨김 주석으로 준비합니다.

## 자료와 배치 위치

| 파일명 | README 위치 | 보여줄 내용 |
| --- | --- | --- |
| overview.png | 상단 Preview | 주변 지형·기지·플레이어가 함께 보이는 대표 화면 |
| building.gif | Building 첫 설명 단락 아래 | 배치 미리보기 → 회전 → 설치 → 복도 연결 |
| inventory.gif | Inventory 첫 설명 단락 아래 | 슬롯 이동·병합과 아이템 수량 변화 |
| production.gif | Production 첫 설명 단락 아래 | 생산량 증가 → 부분 회수 → 시설에 남은 수량 확인 |
| mining.gif | Resource & Mining 첫 설명 단락 아래 | 광물 채광 → 광물 제거 → 인벤토리에 자원 추가 |
| equipment.gif | Equipment 첫 설명 단락 아래 | 주 무기 선택·슬롯 교환 → 실제 장착 객체 변경 |

위 파일명은 준비할 자료의 이름이며 현재 존재하는 파일이 아닙니다. 다른 이름이나 형식으로 저장하면 README의 연결 경로도 실제 파일에 맞춰 바꿉니다.

기능별 배치 순서는 **기능 제목 → 소개 단락 → 사진·GIF와 캡션 → 설계 설명 → 상세 문서 링크**입니다. Preview는 대표 화면에, 기능별 GIF는 해당 기능의 동작에 집중합니다.

## 자료 추가 방법

1. 준비한 이미지·GIF 파일을 이 폴더에 넣습니다.
2. 루트 README에서 해당 위치의 안내 문구와 media 주석을 찾습니다.
3. 안내 문구와 주석 블록을 실제 이미지 문법·캡션으로 교체합니다. 주석 내부에 준비한 문법을 사용할 수 있습니다.
4. 캡션을 실제 촬영 장면에 맞춰 다듬고, README 미리보기에서 이미지와 글자의 가독성을 확인합니다.

파일을 폴더에 넣는 것만으로 이미지가 표시되지는 않습니다. 아직 준비하지 않은 자료는 안내 문구와 숨김 주석을 유지합니다.

예를 들어 building.gif를 추가했다면, README의 해당 안내 문구와 주석을 다음 내용으로 교체합니다.

```markdown
![건물 배치 미리보기와 회전, 설치 후 복도 연결](docs/media/building.gif)

*설치 위치와 방향을 미리 확인하고, 복도 경로를 정해 건물을 연결합니다.*
```

위 경로는 프로젝트 루트 README를 기준으로 합니다.

## 촬영과 캡션

- GIF 하나에는 한 가지 동작 흐름을 담고, 약 5~10초를 출발점으로 조절합니다.
- 인벤토리 수량이나 생산물 보관량이 바뀌는 장면은 변경 전후를 읽을 시간을 둡니다.
- 기능을 이해하는 데 필요한 화면을 담고, 자료끼리 표시 폭과 화면 비율을 가능한 한 맞춥니다.
- 시간이 긴 생산·보충 장면을 배속하거나 중간을 생략하면 캡션에 표시합니다.
- 캡션에는 눈여겨볼 동작이나 결과를 한 줄로 적고 실제 촬영 내용과 일치시킵니다.
- 시연 장면과 별도로 검증한 결과를 구분합니다. 한 장면만으로 모든 실패 처리나 성능이 검증되었다고 설명하지 않습니다.
